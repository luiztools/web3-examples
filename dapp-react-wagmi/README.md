# dapp-react-wagmi

A simple web frontend written with TS/React to integrate with a smart contract in the blockchain (BSC Testnet) and Wagmi.

Smart Contract address: https://testnet.bscscan.com/address/0x31d20731446bdd56b114d9699d392f3a67171f85

## How to Run
1. git clone
2. npm install
3. npm run dev
